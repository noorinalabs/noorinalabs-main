- [Verify the instrument before the reading](feedback_silent_zero_is_not_a_measurement.md) — run the detector on BOTH classes and require it to separate them before reading the number you care about; a zero, a control group, even a 10x lift are each insufficient. A high number is as suspect as a zero.
- [Drop-gate A/B: bidirectional + UNWEIGHTED + Arabic lens](feedback_drop_gate_bidirectional_ab.md) — **a metric derived from a signal a class structurally lacks doesn't under-count it, it ERASES it.** Mention-weighting hid 30.4% of the corpus (45,613 mc=0 rows) and 3 rounds of defects that deleted the Prophet's daughter, his son, and Abu Bakr — each time with an approving reviewer + green CI. da#423.
- [Sweep the expensive stage before launching it](feedback_sweep_expensive_stage_before_launch.md) — launch gate = EVERY defect at-or-before the costly stage merged, not just the blocking one; triage by stage position × re-run cost, not severity; 2nd axis = quality risk. Gate is DYNAMIC, lives in the issue BODY. main#928.
- [Passing repro masks bug (wrong invocation)](feedback_passing_repro_masks_bug.md) — green local repro proves nothing if it used a different invocation form than prod.
- [Query-builder test needs the real engine](feedback_query_builder_test_needs_real_engine.md) — builder unit tests prove the STRING, not that the engine accepts it; execute the built query against a real DB (deploy#606 invalid-Cypher precheck passed 32 tests + 2 reviewers + green CI; only the dry-run caught it). #607.
- [Child checkout goes stale mid-session](feedback_child_checkout_goes_stale_mid_session.md) — /session-start fast-forwards ONCE; merging 9 PRs leaves the child clone 35 commits behind. terraform plan from a stale tree = stale INSTRUCTION against live state (0-to-add today, 1-to-destroy tomorrow). Re-verify HEAD..origin/main==0 before acting on a child tree.
- [memory-judge over-flags fully-stale](feedback_memory_judge_overflags_fully_stale.md) — the Haiku staleness judge's fully-stale bucket is CANDIDATES TO VERIFY, never a delete list: 18 flags / 18 false positives across W28 + #1139 (placeholders, child-repo + external refs, deliberately-absent files, `section_*.md` category errors). Zero deletions is a success outcome. Still run it — #1139 kept all 9 and found 3 real defects the judge never flagged.
- [A corpus misses its constant dimension](feedback_corpus_misses_its_constant_dimension.md) — a differential finds defects only where it VARIES; the held-constant axis is invisible by construction. #1193's 85-shape/7,616-command sweep proved 0 weakened while 24 fail-open holes sat in the one axis it fixed (payload shape). Knowing the rule doesn't prevent it — I repeated it while verifying the reviewer who found it. Enumerate axes, don't just pass. **Cheapest detector (#1269): score the candidate you rejected — 3 charsets scored an identical `420 passed`, so the suite pinned none of them.** Also: mutation-test your OWN new fixtures (`assertIsNotNone` passes when the parser fails by returning a wrong value), and scope a blast-radius survey to the artifact's consumers (parent-repo-only survey said 0; org-wide said 77). W29.
- [A PR-body table is a claim](feedback_pr_body_table_is_a_claim.md) — verify-before-claim applies to measurement tables in PR bodies/reports, not just status claims: code+tests get run while prose gets written from memory. #1277's "main → exit 0" row was never measured (inverted from the issue body); truth was worse. A worked example inside an ISSUE is the author's claim too — re-run it. PR-body edits are silent; correct with a visible comment. W29.
- [Both ends tested, the join untested](feedback_both_ends_tested_join_untested.md) — a value produced in A and consumed in B can have both ends covered while the hand-off is not: deleting `unknown.extend(drift_unknown)` left 75/75 green and turned a total registry outage into "no drift". Mutate the PLUMBING, not just the logic. Sibling: a fixture that REPLACES an adapter can never test that adapter — keep one test driving the real one. W29 #1295.
- [An equivalent mutant is not an inert test](feedback_equivalent_mutant_is_not_an_inert_test.md) — a surviving mutant may be semantically EQUIVALENT (the edit changed nothing), which is indistinguishable from "guard untested" in the output. `\w*`→`\w*?` before a trailing `\b` corrupts nothing; the real corruption needed lazy quantifier AND dropped anchor. Probe the mutated function directly before filing. A wrong repro attached to a right finding manufactures a false negative for the next checker. W29 #1302.
